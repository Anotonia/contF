# Roadmap — contF

**Version:** 0.1.0 foundation (2026-11-07)  
**Decision owner:** Human creative director  
**First use case:** Maya & Ethan original family / character / situation comedy.

## P0: Close one real research-to-feedback loop

| Day | Work | Acceptance evidence |
| --- | --- | --- |
| D0 | Repository foundation, schemas, SOP, synthetic evaluator | CI tests pass; sample review runs |
| D1 | Export/authorize owned-channel data and establish definitions | At least one verifiable video-level observation; source quality documented |
| D2 | Research 10 promising and 10 contrasting reference shorts | Every candidate has dated source, normalization caveat and structured beat hypothesis |
| D3 | Select two patterns, draft three original Maya & Ethan variants | Change log shows independent creative differences; human script approval |
| D4 | Produce small controlled batch with shot/asset/cost logs | Accepted output and per-shot audit available |
| D5+ | Daily observation and review at 24/72/168-hour windows | Comparable cohorts and decision suggestions with evidence |

Dates are relative working days, not a promise that account access or publication exists.

## Milestones

### M1 — Evidence baseline
- [ ] Connect authorized YouTube Studio export or Analytics API; no credential in repo
- [ ] Import format-aware metrics and provenance
- [ ] Document at least one historical cohort for Maya & Ethan
- [ ] Check missingness, time windows, metric units and channel ownership

### M2 — Viral pattern library
- [ ] Build a rights-conscious candidate collection
- [ ] Extract transcript, shot boundaries, scene beat timing, hook / conflict / payoff
- [ ] Include matched non-hits and channel-relative comparisons
- [ ] Produce a reusable *structural* blueprint with explicit hypotheses

### M3 — Controlled variant production
- [ ] Original scripts and character bible
- [ ] Change one creative lever per test where possible
- [ ] FT adapter contract: shot specifications, candidate media, quality gates, cost logs
- [ ] Human confirmation before spend/publish

### M4 — Evolution and decisioning
- [ ] Read-only 24/72/168 h review
- [ ] Cohort-aware results and guardrails
- [ ] Continue / narrow / pivot / pause suggestions
- [ ] Versioned E0–E5 skill promotion proposals; no autonomous application

### M2b — Reference-to-Variant Lab (research workstream, Issue #7)
- [x] Research HYPIT-class editing, analysis and rendering projects using primary repository documentation and license statements.
- [x] Add reference-to-original-variant SOP and a reproducible, no-spend bake-off plan.
- [ ] Benchmark one **owned or expressly licensed** 12–25s Maya & Ethan video (manual vs two tool pathways), recording cut/beat accuracy, reviewer time and failure types.
- [ ] Draft 2+ truly original character/situational comedy variants; human approval for scripts and rights.
- [ ] Decide adopt/narrow/reject; only then design optional FT adapter, model budget and versioned tests.
- [ ] Measure audience effect separately at matched post ages; do not use public virality counts as evidence of causal uplift.

## Non-goals for v0.1

A fully automated scraper, proprietary competitor analytics, guaranteed virality, autonomous mass-posting, billing integration, paid model calls and production YouTube OAuth flows.

## Definition of progress

A successful iteration changes *the next creative decision* using documented evidence, or rejects a weak hypothesis early. Lines of code and number of videos alone do not count.
