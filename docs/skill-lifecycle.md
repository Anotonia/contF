# Skill lifecycle v0.1 (E0–E5)

| Stage | Meaning | Gate |
| --- | --- | --- |
| E0 | Imported pattern/hypothesis | Source and rights provenance captured |
| E1 | Decomposed into an original structural blueprint | Human originality review |
| E2 | Used in an experiment | Experiment and observation IDs exist |
| E3 | Repeatedly positive evidence in comparable use cases | Human reviews confounders and failures |
| E4 | Reliable and economical in production | Quality/cost guardrails reviewed |
| E5 | Mature versioned skill with ongoing monitoring | Human approval; rollback plan |

**No autonomous promotion.** This document defines a lifecycle, not a live registry. A recorded skill version must include references, experiments, favorable and unfavorable outcomes, scope, limitations, owner, reviewer, approval time and rollback target.

A skill is not promoted because a single video performed well. A meaningful regression or platform change opens a review and may demote the skill. Maintain separate skill families for Maya & Ethan family comedy versus professional or documentary long-form.
